# Convertisseur de bases (binaire, décimal, hexadécimal)

Ce projet permet de convertir un nombre entre trois bases :
- binaire
- décimal
- hexadécimal

## Fonctionnalités
- Détection automatique de la base du nombre entré
- Conversion propre et rapide
- Code organisé en modules (`main.py` et `converter.py`)
- Projet personnel réalisé en L1 Informatique

## Exécution
```bash
python3 main.py
